# 見張り番（みはりばん）

膀胱癌（上皮内がん・2nd TUR後）の術後サーベイランスを支援する、毎日1分で入力できる日次記録＋アラートアプリです。高齢のご本人が使うことを最優先に設計しています。

## 特徴
- **単一HTMLファイル**（React不使用・vanilla JS）。`index.html` をスマホのブラウザで開くだけで動作します。
- 記録データは端末内の **localStorage**、尿の写真は **IndexedDB** に保存。JSON（写真も含むバックアップ）／CSV（診察用）でエクスポートできます。
- 文字サイズ最小18px、タップ領域48px以上。落ち着いた和風配色。

## 機能
1. **朝の尿色チェック（写真記録）** — 紙コップの尿を写真にとると、色から7段階レベルを自動推定。タップ1回で確認・微調整でき、レベル6以上で全画面アラート＋病院電話ボタン。写真は端末内に保存され、履歴・診察用まとめで見返せます。
2. **症状チェックリスト** — 4項目（排尿時痛／残尿感／発熱／腰背部痛）をはい/いいえで記録。「腰背部痛＋発熱」は最優先アラート、2日連続の症状は履歴で黄色警告。
3. **AIの目安（自動アドバイス）** — 写真の色・症状・直近の推移から「違和感」を検知し、受診の目安を4段階（落ち着いています／少し気にかけましょう／相談すると安心です／受診・連絡をおすすめします）で表示。**端末内で完結し、写真やデータを外部に送信しません**。あくまで補助で、最終的な医療判断は担当医にゆだねる旨を明記。
4. **検査・治療スケジュール** — BCG注入／膀胱鏡／尿細胞診を登録。7日前・前日にバナー＋通知。膀胱鏡が90日未登録で予約確認を案内。
5. **受診用サマリー** — 直近90日の尿色推移グラフと症状発生日を1画面に集約。CSV書き出し対応。

## 使い方
`index.html` をスマホのホーム画面に追加すると、アプリのように使えます。まず画面右上の⚙からかかりつけ病院の電話番号を登録してください。

## 設計方針
見逃し（偽陰性）を避けるため、警告はやや過剰（偽陽性許容）の閾値に。ただし通常時の画面は平穏に保ち、不安を煽る表現は使いません。

> 本アプリは記録の補助を目的とするもので、医療上の判断は必ず医師にご相談ください。
